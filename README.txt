Qolдау AI — жұмыс істейтін прототиптің бастапқы коды

AI платформасы: тек Google Gemini API (Google AI Studio арқылы). Басқа AI қызметі қолданылмайды.

Іске қосу (Windows, Python 3 орнатылған болуы тиіс):
1. https://aistudio.google.com/apikey мекенжайынан тегін API кілтін алыңыз. Қолжетімділік пен тегін лимит елге және модельге байланысты.
2. Осы буманы компьютерге шығарыңыз.
3. PowerShell ашып, бумаға өтіңіз.
4. Осы терезеде кілтті орнатыңыз: $env:GEMINI_API_KEY="ӨЗ_КІЛТІҢІЗ"
5. python server.py командасын орындаңыз.
6. Браузерде http://localhost:8000 ашыңыз.
7. Пәнді, сыныпты, деңгейін және тапсырманы таңдап, AI көмегін алу батырмасын басыңыз.

Қауіпсіздік: API кілтін ешкімге жібермеңіз және скриншотқа түсірмеңіз. Сервер тек өз компьютеріңізде (127.0.0.1) ашылады. Оқушылардың жеке деректерін енгізбеңіз. Тегін API сұраулары модельді жақсарту үшін пайдаланылуы мүмкін.

Ескерту: Интернет және жарамды тегін Gemini API кілті қажет. Кілтсіз интерфейс ашылады, бірақ AI жауабы берілмейді. Тегін модель лимиттері өзгеруі мүмкін. Бұл алғашқы MVP, толық тексерілген өнім емес.
