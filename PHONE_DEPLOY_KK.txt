Qolдау AI — телефоннан ашылатын сайтты жариялау

Бұл ZIP ішінде мобильді интерфейс пен Gemini API сервері бар. Сайт жарияланбаған: жариялау үшін хостинг аккаунты керек.

1. ZIP-ті ашып, ішіндегі qoldau_ai папкасындағы файлдарды жеке GitHub репозиторийіне жүктеңіз (index.html, server.py, render.yaml). API кілтін репозиторийге ЕШҚАШАН жүктемеңіз.
2. https://aistudio.google.com/apikey адресінде Gemini API кілтін жасаңыз. Құпия сақтаңыз.
3. https://dashboard.render.com сайтына кіріп, New > Blueprint арқылы GitHub репозиторийін қосыңыз. render.yaml файлы сервер параметрлерін береді.
4. GEMINI_API_KEY құпия орта айнымалысына кілтіңізді орнатыңыз. Render тегін жоспарының бар-жоғын және шектеулерін тексеріңіз; тегін инстанс ұйқыға кетуі мүмкін.
5. Deploy аяқталған соң Render берген https://...onrender.com мекенжайын телефоннан ашыңыз. Жоба URL-і тек жарияланған соң пайда болады.
6. Математика, қазақ тілі, ағылшын тілі бойынша тапсырмаларды тексеріңіз. Gemini тегін лимиттері, қолжетімді модель атауы өзгеруі мүмкін.

МАҢЫЗДЫ: бұл ашық демо, пайдаланушыларды тіркеу/шектеу және контент модерациясы әзірге жоқ. Көпшілікке жарияламай тұрып қорғаныс пен лимиттерді қосыңыз. Балалардың жеке деректерін енгізбеңіз.
